# ☕ Java10x – Java Core

Repositório com os exercícios e desafios que desenvolvi durante o
**Java Core** da Java10x (Turma 2025), do nível iniciante ao avançado.

## 🎯 Objetivo
Consolidar os fundamentos de Java e orientação a objetos antes de
seguir para Spring Boot.

## 📚 O que foi estudado

### Iniciante
Variáveis e tipos, condicionais, Scanner, switch, ternários,
laços de repetição, arrays e noções de Garbage Collector.

### Intermediário
Classes e objetos, herança, polimorfismo, interfaces, classes abstratas,
construtores, overload/override, encapsulamento, enums, Generics,
Records e Collections (List, Stack, Queue, LinkedList, HashSet,
LinkedHashSet, TreeSet).

### Avançado
Compilação x execução, escopo estático, Big O e **Streams** (parte prática).

| Pasta | Conteúdo |
|-------|----------|
| `src/Iniciante` | Tipos de dados, condicionais, arrays, Desafios 1 e 2 |
| `src/Intermediario` | Aulas de POO e Collections (`Aula1a5` a `Aula26a37`) e Desafios 3 a 6 |
| `src/Avancado.Stream` | Prática de Streams |

## ▶️ Como executar
- Java 21
- Abra no IntelliJ e rode a classe `Main` do pacote desejado
